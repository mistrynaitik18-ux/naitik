ℹ About CyberSentinel IR

CyberSentinel IR is an educational cybersecurity incident response simulation platform built for the IBM Cybersecurity Bootcamp.

Version1.0.0
StackHTML5 · CSS3 · Vanilla JS
StoragelocalStorage (browser)
AuthorIBM Bootcamp Student
🎓 Learning Outcomes
  • Incident detection, triage, and classification
  • NIST SP 800-61 IR lifecycle
  • Containment, eradication, and recovery
  • Evidence handling and chain of custody
  • IOC identification and threat intelligence
  • Post-incident review and reporting
⚠ Disclaimer

This application is a purely educational simulation. It does not send real phishing emails, execute malware, attempt unauthorized access, or interact with any real external system. All incidents, IP addresses, domains, file hashes, and indicators of compromise are entirely fictional. Use of this tool is intended for learning purposes only.
